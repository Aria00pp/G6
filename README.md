# G6 AutoLISP Tool

G6 is an AutoLISP tool for drawing chained line segments (with TAB cycling angles) and optionally creating aligned dimensions.

## Installation

Option A (APPLOAD)
1. Download `G6.lsp`.
2. In AutoCAD, run `APPLOAD`.
3. Select `G6.lsp` and load it.

Option B (Command line)
1. Put `G6.lsp` somewhere on your disk.
2. In AutoCAD, run:
   `(load "C:/full/path/to/G6.lsp")`

## Usage
1. Run the command:
   `G6`
